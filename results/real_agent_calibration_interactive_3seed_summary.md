# Three-seed interactive Mode L calibration summary

Inputs are the three independent n=48 interactive Qwen2.5-7B runs with seeds
20261002, 20261003 and 20261004. Across 144 test tenants and 576 queries per
condition:

| condition | successes / queries | success |
|---|---:|---:|
| public strategy | 433 / 576 | 0.7517 |
| private strategy | 434 / 576 | 0.7535 |

The pooled tenant-paired difference is **+0.17 pp**. A deterministic 200,000
resample bootstrap over tenant differences gives **[-1.74, +2.08] pp** at 95%.
The per-seed differences are +3.125 pp, −2.083 pp and −0.521 pp. This is far
below the planned 5 pp G1 threshold and the interval includes zero.

The summary is generated by
`python -m analysis.summarize_interactive_calibration`; raw inputs remain in
the three seed-specific JSON files. This is non-DP calibration evidence only.
