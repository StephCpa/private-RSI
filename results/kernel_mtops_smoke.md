# Kernel × MT-Ops synthetic-agent smoke

Generated by `python -m experiments.kernel_mtops_smoke`.

This run connects MT-Ops v0's two deterministic baselines to the minimal
kernel. It checks data flow, clipping, ledger reservation, Gaussian release-all
and exponential winner-only selection. It uses no LLM and is not evidence of
DP-RAE utility or cross-tenant meta-learning.

The full JSON contains the dataset hash, bounded raw mean contributions, noisy
sums, and both public ledger states. The oracle is excluded from the candidate
pool so it cannot inflate mechanism selection.
